# Wheel of Life – HTML Project

This repository hosts my **Wheel of Life** project.  
It serves two purposes:  
1. A **training exercise** to learn and practice GitHub, version control, and GitHub Pages.  
2. A **self-reflection tool** that visualizes different areas of life in a chart to assess balance and identify opportunities for growth.  

## Live Demo
You can view the project online via GitHub Pages:  
👉 [Wheel of Life](https://<username>.github.io/<repository-name>/)

## Features
- Interactive **Wheel of Life** chart built with HTML, CSS, and JavaScript.  
- Simple and responsive design.  
- Easy to customize with your own life areas and categories.
